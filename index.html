Boundary Techniques

Two Ways to Handle Screen Edges

Depending on your game design, you can choose between two main boundary rules:

Method 1

Wrap-Around Logic

When the sprite moves off one edge of the screen, it instantly reappears on the opposite edge!

👻

Remember Pac-Man!

Pac-Man exits the left tunnel and seamlessly re-enters from the right tunnel!

Method 2

Stop at Boundary

The screen edges act like solid walls. The sprite's position is clamped so it cannot move past the edge!

🧱

Like Hitting a Wall!

Used in games like Pong or Space Invaders to keep players inside the screen bounds.

Let's explore how to write the Python code for each method, starting with Wrap-Around Logic!
Method 1

Method 1: Wrap-Around Logic

Wrap-Around Simulator WIDTH = 400px
x = 0 ◄──────── WIDTH: 400px ────────► x = 400
🚀
# Wrap-Around Code Logic:
# Check Left Boundary:
if spaceship.x < 0:
spaceship.x = WIDTH

# Check Right Boundary:
if spaceship.x > WIDTH:
spaceship.x = 0

Current X Pos: 200
Status: Inside Bounds
Observe: When moving left slowly past x < 0, the ship resets to x = 400 on the far right edge!

Method 2

Method 2: Stop at Boundary Logic

# Stop at Wall Logic:
# Stop at Left Edge:
if spaceship.x < 0:
spaceship.x = 0

# Stop at Right Edge:
if spaceship.x > WIDTH - ship_width:
spaceship.x = WIDTH - ship_width
Canvas Width: WIDTH = 400
Current X Pos: 200
Wall Contact: Clear
Stop-At-Wall Simulator Boundaries Active
WALL x = 0 ◄────── 400px ──────► WALL x = 360
🚀
Observe: Moving right clamps at x = 360 (accounting for ship width), touching the right wall!
